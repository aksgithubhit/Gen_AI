Gen AI Project

This project is a Generative AI application that uses Large Language Models (LLMs) to generate responses based on user input. The application allows users to interact with AI through a simple interface and receive intelligent outputs such as answers, summaries, or generated content.


Features
AI powered text generation
User prompt input
Real-time AI responses
Simple and responsive interface
Backend API integration with AI model


Technologies Used
Frontend: React / HTML / CSS / JavaScript
Backend: Node.js / Express
AI Integration: OpenAI API or other LLM APIs
Database : MongoDB
